# Aulas

Esta pasta reúne as apresentações e os demais materiais de apoio das aulas teóricas da disciplina **BIE5781 - Introdução à modelagem estatística na pesquisa em biologia**.

Os arquivos devem ser organizados, preferencialmente, de acordo com a numeração e os títulos do [cronograma](../index.Rmd):

- `Aula_01_fundamentos`
- `Aula_02_verossimilhanca`
- `Aula_03_modelo_linear`

Os materiais podem ser adicionados em PDF, HTML ou outro formato adequado para consulta durante a disciplina.
